# 인터페이스 IP

**목적**: loopback0과 PE2 방향 링크 IP를 넣고, 링크를 VRF TENANT-A에 소속

**핵심**

- CX1은 1/1/1에 10.0.20.5/31(PE2 Gi2/0), CX2는 10.0.20.7/31(PE2 Gi3/0)
- 링크는 rf attach TENANT-A를 **먼저**, ip address를 나중에 입력. 순서가 바뀌면 IP가 지워질 수 있음
- VRF TENANT-A의 RD는 65201:1(CX 로컬 값). PE2의 RD 65000:1과 다름
- CX3은 L2 전용이라 이 단계가 없음
- VSX keepalive 링크의 IP(10.2.254.x)는 [VSX](03-vsx.md) 단계에서 입력

**확인 명령**: `show vrf`, `show ip interface brief`, `ping 10.0.20.4 vrf TENANT-A`

파일: `ip.aos`

```text
! Aruba AOS-CX - 인터페이스 IP 샘플 (CX1 기준, 값은 문서의 IP 표 기준)
! 확인: show vrf / show ip interface brief / show interface brief
! CX2는 loopback 0 을 10.2.0.2/32, 1/1/1 을 10.0.20.7/31 로 바꾼다 (PE2 Gi3/0 방향)
! CX3는 L3 인터페이스가 없다 (L2 전용)
!
vrf TENANT-A
    rd 65201:1
!
interface loopback 0
    ip address 10.2.0.1/32
!
! L3 링크: vrf attach를 먼저, ip address를 나중에 입력
interface 1/1/1
    no shutdown
    description PE2 to Gi2/0
    vrf attach TENANT-A
    ip address 10.0.20.5/31
!
```
