# 1단계: DC1 (Arista) 패브릭

## 목표

Host A, B, C 사이에 L2(같은 VLAN)와 L3(다른 VLAN) 통신이 됨

## 켜는 노드

Arista 6대(spine1, spine2, leaf1~leaf4), Host A, B, C, MGMT-SW. 메모리 약 14GB 예상([리소스 계획](../00-overview/04-resource-plan.md)).

## 순서

시작 전에 DC1의 [VLAN과 IP 계획](../baseline/dc1/02-vlan-ip.md)을 확인

| 순서 | 할 일 | 참고 문서 | 확인 |
|---|---|---|---|
| 1 | GNS3에서 노드를 배치하고 링크 연결 | [포트 매핑](../baseline/dc1/01-overview.md) | 링크 초록색 |
| 2 | 모든 노드에 기본 설정(이름, 계정, 관리 IP). **먼저 ZTP 끄기**: [ZTP 끄기](../samples/dc1/02-ztp-disable.md). 이어서 `service routing protocols model multi-agent`를 설정하고 `write memory` 후 `reload`(EVPN 필수) | [샘플: 기본 설정](../samples/dc1/01-base.md), [비밀번호 위치](../samples/dc1/04-password.md) | 콘솔 로그인 |
| 3 | OSPF underlay | [기준](../baseline/dc1/03-ospf-underlay.md), [샘플](../samples/dc1/05-ospf-underlay.md) | [검증](../verification/dc1/01-ospf-underlay.md) |
| 4 | MLAG (leaf1/2, leaf3/4). OSPF와 독립이라 3번 전에 해도 됨 | [기준](../baseline/dc1/04-mlag.md), [샘플](../samples/dc1/06-mlag.md) | [검증](../verification/dc1/02-mlag.md) |
| 5 | 호스트 설정 (Host A bond, 나머지 IP) | [호스트 IP](../samples/host/01-ip-config.md), [LACP bond](../samples/host/02-bond-lacp.md) | 게이트웨이 ping |
| 6 | EVPN-VXLAN (spine, leaf). **EVPN 전에 `multi-agent`를 `write memory` 후 `reload`로 적용해 둘 것** | [기준](../baseline/dc1/05-evpn-vxlan.md), [leaf 샘플](../samples/dc1/07-evpn-vxlan-leaf.md), [spine 샘플](../samples/dc1/08-evpn-spine.md) | [검증](../verification/dc1/03-evpn-vxlan.md) |
| 7 | 저장 | `write memory`, 컨피그를 `configs/dc1/`에 보관 | |

## 완료 기준

- 모든 검증 문서의 확인 항목이 기대 결과와 같음
- Host A에서 Host B(같은 VLAN)와 Host C(다른 VLAN)에 ping이 됨
