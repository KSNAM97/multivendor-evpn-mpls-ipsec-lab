# 1단계: DC1 (Arista) 패브릭

파견 순서: 순서 1, 2, 4, 5는 1차 파견(언더레이), 3(OSPF)은 2차 ①, 6(EVPN-VXLAN)은 2차 ③. 고객사 간 순서는 [프로젝트 요약의 구축 순서](../docs/01-project-summary.md#구축-순서)

## 목표

Host A, B, C 사이에 L2(같은 VLAN)와 L3(다른 VLAN) 통신이 됨

## 켜는 노드

Arista 8대(spine1, spine2, leaf1~leaf4, border-leaf1·2), Host A~D, MGMT-SW1, MGMT-PC1(관리 노드는 관리망 구성과 검증 때만 켬). 메모리는 [리소스 계획](../00-overview/04-resource-plan.md) 참조. 기존 6대 기준 약 14GB 예상([리소스 계획](../00-overview/04-resource-plan.md)).

## 순서

시작 전에 DC1의 [VLAN과 IP 계획](../baseline/dc1/02-vlan-ip.md)을 확인

| 순서 | 할 일 | 참고 문서 | 확인 |

| 2 | 모든 노드에 기본 설정(이름, 계정, 관리 IP). **먼저 ZTP 끄기**: [ZTP 끄기](../samples/dc1/02-ztp-disable.md). 이어서 `service routing protocols model multi-agent`를 설정하고 `write memory` 후 `reload`(EVPN 필수) | [샘플: 기본 설정](../samples/dc1/01-base.md), [비밀번호 위치](../samples/dc1/04-password.md) | 콘솔 로그인 |

## 완료 기준

- 모든 검증 문서의 확인 항목이 기대 결과와 같음
- Host A에서 Host B(같은 VLAN)와 Host C(다른 VLAN)에 ping이 됨
